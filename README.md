# Приложение "Канбан-доска"

*В проекте реализованы следующие функции:*

- авторизация и регистрация для пользователя;
- индикатор загрузки перед появлением задач на доске;
- создание новой задачи, ее просмотр, редактирование и удаление;
- есть страница 404, с которой пользователь может перейти на главную страницу.
